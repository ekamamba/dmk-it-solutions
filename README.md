# DMK IT Solutions — Marketing Website v2

This is a brand-new Next.js application based on the current public DMK IT Solutions service portfolio and the new outcome-focused marketing strategy.

## Positioning

Technology that helps your business grow.

Primary customer funnel:

Free Website Review → $199 Business Technology Checkup → $749 Website Rescue → $1,995+ Business Growth Website → $99/$199 monthly care → higher-value data, automation, cloud and IT consulting.

## Included

- Outcome-focused homepage
- Three productized packages
- Free Website Review landing page
- Lead capture endpoint
- Thank-you page
- Business-growth positioning
- Data & analytics positioning
- Industry targeting
- Responsive Tailwind UI
- Metadata/SEO foundation

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production notes

1. Replace the console-only `/api/contact` handler with Resend, your CRM, or another lead-management provider.
2. Add the real DMK logo to `public/` if desired.
3. Add verified testimonials/case studies only where you have permission and supporting evidence.
4. Configure `dmkitsolutions.com` DNS/Vercel hosting after deployment.
5. Add Google Analytics/Search Console after the production domain is confirmed.
6. Add legal/privacy pages before collecting production leads.
